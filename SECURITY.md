# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository from the
**Security** tab, then choose **Report a vulnerability**. Include the affected
component, reproduction steps, impact, and any suggested mitigation. If private
reporting is unavailable, contact the maintainer through the contact method on
their GitHub profile without including sensitive details in a public message.

You should receive an acknowledgement within seven days. Please allow time for
investigation and a fix before public disclosure.

## Supported versions

Security fixes are applied to the latest revision on the default branch. This
project does not currently maintain separate release branches.
